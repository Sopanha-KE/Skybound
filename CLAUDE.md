# SkyEngine / Skybound: instructions for Claude

Read in this order before doing anything:
1. `docs/PROGRESS.md` for current status, what was verified, and the next step.
2. `docs/GameEngine.md` for the engine rules, architecture and phased roadmap (source of truth for the engine).
3. `docs/GAME_BRIEF.md` for the game design brief (source of truth for the game).

Rules that matter most: work one phase at a time; wait for developer approval before starting a phase; never claim something works unless it was built or run (use Built / Unit tested / Run manually / Not verified); Windows MSVC is the primary build. Build and test commands are in `AGENTS.md` and `docs/build.md`. Update `docs/PROGRESS.md` at the end of every phase.
